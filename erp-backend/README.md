# Amar Packers ERP - Backend

Node.js / Express / MongoDB backend API for the Amar Packers ERP system.

## Author
**Vishal Bhadauria**

## Technologies Used
- Node.js
- Express.js
- MongoDB & Mongoose
- TypeScript

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env`:
   - `MONGO_URI`
   - `PORT` (default 5000)
   - `CLIENT_ORIGIN`

3. Start development server:
   ```bash
   npm run dev
   ```

## Production
Build and start the application:
```bash
npm run build
npm start
```
